# VARIABLE_AUDIT

실제 데이터 컬럼, 코드에서 사용한 변수명, 원고에서 말하는 개념 변수가 서로 맞는지 검증한다.

## 사용 원칙

- 코드가 `04_analysis/`에 정리되어 있다는 사실만으로 변수 사용이 맞다고 보지 않는다.
- 원자료 또는 데이터 딕셔너리의 실제 컬럼명을 먼저 확인한다.
- 코드에서 rename, recode, join, filter, aggregate가 일어나는 지점을 확인한다.
- 원고의 변수 설명과 코드의 변수 생성 방식이 다르면 `수정 필요`에 표시한다.
- 변수 검증이 끝나기 전에는 `Result.md`의 표, 계수, 해석을 확정하지 않는다.

## 상태값

- 확인 전
- 일치
- 불일치
- 애매함
- 수정 필요
- 제외

## 코드 체크리스트

- [ ] 실제 데이터 컬럼 목록을 확인했다.
- [ ] 코드에서 쓰는 모든 주요 변수가 실제 데이터 컬럼 또는 생성 변수와 연결된다.
- [ ] rename/recode/join/filter/aggregate 단계가 표에 반영되어 있다.
- [ ] 원고의 변수 정의가 코드의 변수 생성 방식과 일치한다.
- [ ] 분석 표본 수와 필터 조건이 코드, 결과표, 원고에서 일치한다.
- [ ] 불일치 또는 애매한 변수는 `Result.md`와 `Methods.md` 확정 전에 해결했다.
