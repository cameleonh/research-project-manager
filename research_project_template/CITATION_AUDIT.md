# CITATION_AUDIT

본문에 인용한 논문과 참고문헌 목록이 서로 맞는지, 그리고 각 인용 논문이 실제로 존재하는지 검증한다.

## 사용 원칙

- 본문 인용과 참고문헌 목록을 양방향으로 대조한다.
- 본문에만 있고 참고문헌 목록에 없는 항목은 `본문만 있음`으로 표시한다.
- 참고문헌 목록에만 있고 본문에서 인용되지 않은 항목은 `목록만 있음`으로 표시한다.
- 실재 확인은 검색 결과 제목만 보지 말고 DOI resolver, publisher page, Crossref, PubMed, KCI, RISS, DBpia, Scopus 등 확인 가능한 출처를 근거로 남긴다.
- 제목, 저자, 연도, 학술지, DOI 중 핵심 정보가 맞지 않으면 `수정 필요`로 둔다.
- `CITATION_AUDIT.md`에 unresolved 항목이 남아 있으면 투고 전 참고문헌을 확정하지 않는다.

## 본문-참고문헌 대조 상태값

- 확인 전
- 일치
- 본문만 있음
- 목록만 있음
- 서지정보 불일치
- 수정 필요
- 제외

## 실재 확인 상태값

- 확인 전
- 확인됨
- 확인 실패
- DOI 불일치
- 제목/저자 불일치
- 공식 출처 없음
- 수정 필요

## 체크리스트

- [ ] `06_manuscript/*.md` 또는 최종 원고에서 본문 인용을 모두 추출했다.
- [ ] 참고문헌 목록 또는 BibTeX/RIS/Zotero export와 본문 인용을 대조했다.
- [ ] 본문 인용이 있는 모든 항목이 참고문헌 목록에 있다.
- [ ] 참고문헌 목록의 모든 항목이 본문에서 인용되었거나 제외 사유가 있다.
- [ ] DOI가 있는 항목은 DOI resolver 또는 publisher page에서 확인했다.
- [ ] DOI가 없는 항목은 공식 학술 DB나 출판사/학회 페이지에서 확인했다.
- [ ] 저자, 연도, 제목, 학술지, 권호, 페이지, DOI의 불일치를 수정했다.
