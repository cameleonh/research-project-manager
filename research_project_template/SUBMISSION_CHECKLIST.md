# SUBMISSION_CHECKLIST

투고 직전에 여는 파일이다. 이 파일의 목적은 새 아이디어를 더하는 것이 아니라, 현재 원고가 심사대에 올라갈 수 있는지 판정하는 것이다.

## 사용 원칙

- `선행연구 더 읽기`, `분석 더 하기`처럼 끝이 없는 항목은 넣지 않는다.
- 새 분석이 필요하면 먼저 그것이 핵심 주장 방어에 필수인지 판단한다.
- 필수가 아니면 `PARKING_LOT.md`로 보낸다.
- 마지막 목표는 완벽한 원고가 아니라 투고 가능한 원고다.

## 1. 논문 정체성 잠금

- [ ] 제목 확정
- [ ] 핵심 연구질문 1개 확정
- [ ] 핵심 주장 1-2문장 확정
- [ ] 이 논문에서 주장하지 않을 것 명시
- [ ] 타깃 학술지 1순위 확정
- [ ] 타깃 학술지 2순위 확정

## 2. 원고 완성도

- [ ] 초록 완성
- [ ] 서론 완성
- [ ] 선행연구 완성
- [ ] 자료와 방법 완성
- [ ] 결과 완성
- [ ] 논의 완성
- [ ] 결론 완성
- [ ] 한계와 후속연구 문단 완성

## 3. 결과 검증

- [ ] 최종 표본 수 확인
- [ ] 제외 기준 확인
- [ ] 주요 변수 정의 확인
- [ ] `VARIABLE_AUDIT.md`에서 핵심 변수의 실제 데이터 컬럼, 코드 변수명, 원고 변수명이 일치
- [ ] 핵심 계수 / OR / HR / p-value 확인
- [ ] 표와 본문 숫자 일치 확인
- [ ] 그림과 본문 해석 일치 확인
- [ ] 초록의 수치와 본문 수치 일치 확인
- [ ] 연구질문, 결과, 논의의 방향 일치 확인

## 4. 표와 그림

- [ ] 표 번호와 제목 정리
- [ ] 그림 번호와 제목 정리
- [ ] 표 주석과 약어 설명 확인
- [ ] 그림 해상도와 파일 형식 확인
- [ ] 본문에서 모든 표와 그림을 순서대로 언급

## 5. 투고 패키지

- [ ] 참고문헌 형식 통일
- [ ] 국문초록 확인
- [ ] 영문초록 확인
- [ ] 키워드 확인
- [ ] 저자정보와 소속 확인
- [ ] 연구윤리 / IRB / 자료출처 문장 확인
- [ ] 이해상충 문장 확인
- [ ] 학술지 투고 양식 반영
- [ ] 커버레터 작성

## 6. 최종 판정

- [ ] 새 분석 없이 투고 가능
- [ ] 남은 수정은 문장, 형식, 표기 수준
- [ ] 공저자 또는 지도교수 최종 확인 필요 여부 결정
- [ ] 투고일 확정
- [ ] 투고본 저장 위치 확정
